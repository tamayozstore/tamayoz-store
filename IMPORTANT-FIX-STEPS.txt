حل Bucket not found + اللوجو + فئة سنة لسنتين ونص
===================================================

1) لا تمسح صور GitHub القديمة ولا المنتجات الموجودة.
2) ادخل Supabase > SQL Editor > New query.
3) افتح الملف RUN-THIS-ONCE-FIX.sql وانسخ محتواه بالكامل واضغط Run مرة واحدة فقط.
   الملف لا يمسح المنتجات أو الطلبات ولا يعيد Seed للمنتجات القديمة.
4) ارفع ملفات الكود الموجودة في هذه الحزمة إلى GitHub واعمل Replace للملفات المتكررة.
5) لا ترفع أو تمسح أي JPG/PNG قديمة من GitHub.
6) استنى Vercel Deploy ثم Ctrl+Shift+R وافتح /admin.html.
7) في Overview هتشوف Storage جاهز ✓ لو كل شيء تمام.

الجديد في قائمة رفع المنتجات:
- كل صورة لها checkbox وهي لسه في مرحلة التعديل قبل الحفظ.
- تحديد الكل / مسح التحديد.
- تغيير الفئة للمحدد مرة واحدة.
- مميز/عادي ومتـاح/نفد للمحدد.
- حذف المحدد من قائمة الرفع.
- رفع المحدد فقط أو رفع الكل.
- لو حصل خطأ بعد حفظ جزء من المنتجات، المنتجات اللي لم تُحفظ تفضل في القائمة ببياناتها بدل ما تبدأ من الصفر.

فئة من سنة لسنتين ونص:
- الرابط الجديد يستخدم category=1-2-5، والكود يحوله داخلياً للقيمة الصحيحة 1-2.5.
- SQL يصلح أي قيم قديمة محتملة بدون حذف المنتجات.
