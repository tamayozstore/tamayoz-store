إصلاح المشكلة الحالية - بالترتيب
================================

1) Supabase > SQL Editor > New query
   شغّل الملف: RUN-THIS-NOW-SAFE.sql
   لا تشغّل RUN-THIS-ONCE-FIX.sql القديم.

2) في آخر التنفيذ لازم تشوف:
   products_table_ready = true
   bucket_ready = true

3) ارفع ملفات هذه النسخة على GitHub واعمل Replace للكود فقط.
   مهم: لا تمسح صور GitHub القديمة ولا مجلد year1 ولا logo.png.

4) استنى Vercel يعمل Deploy واعمل Ctrl+Shift+R.

5) صفحة "من سنة لسنتين ونص" ستعرض المنتجات القديمة مباشرة من الصور الموجودة بالفعل في GitHub.

6) لو عايز المنتجات القديمة تظهر داخل لوحة Admin للتعديل/التحديد/الحذف:
   Admin > الصور واللوجو > استرجاع بيانات المنتجات القديمة > استيراد المنتجات القديمة الناقصة
   الزر يضيف البيانات الناقصة فقط، ولا يرفع الصور ولا يستبدل منتج موجود بنفس SKU/الاسم والصورة.

7) بعد ذلك المنتجات الجديدة تترفع من Admin إلى Supabase Storage كالمعتاد.
